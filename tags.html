Un «site.posts | size» a secas contaría esos 39 ficheros y daría una cifra falsa. «site.tags | sort» ordena por nombre de materia. Sin el sort, Jekyll las devuelve en orden de primer uso cronológico, que en pantalla parece aleatorio. Es «sort» y no «sort_natural» porque aquí cada elemento es el par [nombre, posts]: sort_natural llamaría a downcase sobre el par y reventaría. {% endcomment %} {% assign materias = site.tags | sort %} {% assign articulos = site.posts | where: "layout", "post" %} {% assign clasificaciones = 0 %} {% for materia in materias %}{% assign clasificaciones = clasificaciones | plus: materia[1].size %}{% endfor %}
