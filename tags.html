Un «site.tags | sort» a secas compara byte a byte: dejaba «SEO/GEO» la primera (las mayúsculas van antes que las minúsculas) y «Ética» la última (la É está por encima de la z). Aquí se ordena por el slug de cada materia, que «slugify: 'latin'» devuelve en minúsculas y sin tildes, y que además es el id del ancla: se calcula una vez y sirve para las dos cosas. Empaquetar «slug|nombre» en una cadena y trocearla después es la manera de ordenar por una clave derivada en Liquid, que no tiene sort_by. Los separadores «|» y «#» no aparecen en ningún nombre de materia. {% endcomment %} {% assign indice = "" %} {% for materia in site.tags %} {% assign slug = materia[0] | slugify: 'latin' %} {% assign indice = indice | append: slug | append: '|' | append: materia[0] | append: '#' %} {% endfor %} {% assign materias = indice | split: '#' | sort %} {% comment %} Va oculto de partida y lo muestra clean-blog.js: sin JavaScript sería un control muerto, y con el atributo hidden tampoco deja hueco en blanco.
